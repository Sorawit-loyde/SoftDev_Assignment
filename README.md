# SoftDev Assignment

All Software Developer assignments are here

## Overview

This repository contains assignments for software development courses, primarily using Python and Docker.

## Requirements

- Python 3.7+
- Docker (for assignments using Dockerfile)
- (Optional) HTML browser for web-based assignments

## Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Sorawit-loyde/SoftDev_Assignment.git
   cd SoftDev_Assignment
   ```

2. **Python dependencies:**
   If present:
   ```sh
   pip install -r requirements.txt
   ```

3. **Docker assignments:**
   ```sh
   docker build -t assignment .
   docker run assignment
   ```

## Usage

- Navigate to folders for each assignment.
- Follow README or instructions in each folder.
